## Featured project

### [Jeevan Mitra](https://github.com/manojga56565/Jeevan-Mitra)

**A coordination layer connecting hospitals, blood banks, and potentially eligible blood donors.**

Jeevan Mitra addresses a coordination problem during urgent blood requirements. Families and hospitals may struggle to reach suitable donors quickly because information is spread across different people and organizations.

**Proposed workflow**

Hospital requirement → Donor matching → Relevant alerts → Donation coordination → Verification

**Key project areas**
- Blood requirement coordination
- Donor discovery using blood group and location
- Donor eligibility and donation cooldown checks
- Request tracking and coordination
- QR-based donor identification and hospital-side verification

**Safety and project status**

Jeevan Mitra does not replace blood banks or healthcare professionals. Donor screening, compatibility testing, collection, storage, and transfusion decisions must remain with authorized blood banks and qualified professionals.

The project is in development. Frontend and backend workflows still require integration, deployment, and end-to-end testing. Features will be described as complete only after they are verified.

## Other projects

### [Vulnerability Scanner](https://github.com/manojga56565/Vulnerability.scanner)

A Python command-line learning tool for basic web and network security checks. It reviews six common HTTP security headers, inspects TLS certificate issuer and expiry details, scans selected TCP ports, highlights selected potentially risky exposed services, and generates standalone HTML reports. It also stores local scan history.

**Scope:** An educational scanner, not a comprehensive vulnerability assessment platform. Findings require manual validation and scans must only target authorized systems.

### [Password Strength Analyzer](https://github.com/manojga56565/Password-Strength-Analyzer)

A Python command-line learning project that evaluates password length and character variety, checks common passwords and simple patterns, estimates character-pool entropy, provides improvement suggestions, and tracks password reuse through a local SQLite history.

**Scope:** An educational tool, not a password manager or production authentication system. Its README documents important limitations in its current password-history hashing and password-generation methods.
